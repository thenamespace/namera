## Other Connections

[Grok](/docs/mcp/clients/grok) currently requires a remote endpoint for its
documented MCP connector, so it cannot connect directly to Namera's local server.
For a client not listed here, see [Other Clients](/docs/mcp/clients/other-clients).

These instructions use the clients' documented local MCP configuration formats.
Tool approval controls and availability can vary by version or organization
policy. Check each page's upstream documentation if its settings have moved.
