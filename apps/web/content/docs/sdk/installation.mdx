## Requirements

Use **Node.js 24.14+**, or a modern browser with Fetch and Web Crypto.

## Install

<Tabs items={["npm", "pnpm", "yarn", "bun"]}>
<Tab value="npm">

```sh
npm install @namera-ai/sdk
```

</Tab>
<Tab value="pnpm">

```sh
pnpm add @namera-ai/sdk
```

</Tab>
<Tab value="yarn">

```sh
yarn add @namera-ai/sdk
```

</Tab>
<Tab value="bun">

```sh
bun add @namera-ai/sdk
```

</Tab>
</Tabs>

Continue to [Getting Started](/docs/sdk/getting-started) to create a client and
make your first request.
