Send a small test transaction on
**Base Sepolia**. Add the TypeScript snippets to one `index.ts` file in order.

## Install the SDK

```sh
npm install @namera-ai/sdk viem
```

## Set Up Your Account

In the [Namera dashboard](https://dashboard.namera.ai):

1. Create or choose an account. Choose a separate recipient wallet you control.
2. Create a **session key** that allows a native transfer to that
   recipient, with a spending limit of **0.001 ETH**.
3. Approve its installation on **Base Sepolia** and wait for it to become active.
4. Create an API key with access to only this session key for this walkthrough.

Fund the account with **0.001 Base Sepolia test ETH** and save your API key:

```dotenv title=".env"
NAMERA_API_KEY=your_api_key
```

<Callout type="warn" title="Keep credentials private">
  Keep `.env` out of Git and API keys out of browser code.
</Callout>

## Create a Client

```ts title="index.ts"
import { NameraClient } from "@namera-ai/sdk";

const namera = new NameraClient({
  apiKey: process.env.NAMERA_API_KEY!,
});
```

## Execute a Transaction

This sends **0.001 test ETH** on Base Sepolia. Replace the example address below
with the separate recipient wallet allowed by your session key.

```ts title="index.ts"
import { parseEther } from "viem";

const execution = await namera.executions.execute({
  namespace: "eip155",
  walletId: session.walletId,
  sessionKeyId: session.id,
  chainId: "eip155:84532",
  calls: [
    {
      to: "0x2222222222222222222222222222222222222222",
      value: parseEther("0.001"),
      data: "0x",
    },
  ],
  sponsor: true,
});

if (!execution.success) throw new Error(execution.error.message);

console.log(execution.data);
```

<Callout type="warn" title="This submits a real testnet transaction">
  The selected key must permit the call and be installed on Base Sepolia. Gas sponsorship uses your
  workspace's allowance; it does not fund the transfer.
</Callout>

`prepared` means the operation is queued for broadcast.

## Get Submission Status

Use the submission ID from the execution result:

```ts title="index.ts"
const status = await namera.executions.getStatus(execution.data.submissionId);

if (!status.success) throw new Error(status.error.message);

console.log(status.data);
```

<div className="docs-response">

```json
{
  "namespace": "eip155",
  "submissionId": "0199dfe1-0000-7000-8000-000000000003",
  "status": "submitted",
  "userOperationHash": "0x1111111111111111111111111111111111111111111111111111111111111111"
}
```

</div>

Check the same submission again after a short delay while its status is
`reserved`, `prepared`, or `submitted`. Stop on `confirmed` or `failed`.

- **Confirmed:** `status.data.execution` contains the execution record.
- **Failed:** the submission did not complete successfully.

<Callout title="Accepted is not confirmed">
  `success: true` means the SDK request succeeded. Read `data.status` for the transaction outcome.
  Poll the existing submission instead of calling `execute()` again to check progress.
</Callout>

## Run It

Run from the directory containing `index.ts` and `.env`:

```sh
node --env-file=.env index.ts
```

The script submits **one new transaction each time you run it** and checks its
status once. To check that same transaction later, keep its submission ID and
call only `getStatus()`.

For message signing, see the [quick examples](/docs/sdk#quick-examples).
