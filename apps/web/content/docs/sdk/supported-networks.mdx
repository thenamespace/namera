Namera supports ten EVM networks. Use `namespace: "eip155"` and the full
`chainId` string when executing, simulating, or signing.

## Mainnets

| Network      | Chain ID       |
| ------------ | -------------- |
| Ethereum     | `eip155:1`     |
| Base         | `eip155:8453`  |
| Arbitrum One | `eip155:42161` |
| OP Mainnet   | `eip155:10`    |
| Arc          | `eip155:5042`  |

## Testnets

| Network          | Chain ID          |
| ---------------- | ----------------- |
| Ethereum Sepolia | `eip155:11155111` |
| Base Sepolia     | `eip155:84532`    |
| Arbitrum Sepolia | `eip155:421614`   |
| OP Sepolia       | `eip155:11155420` |
| Arc Testnet      | `eip155:5042002`  |

The [Getting Started](/docs/sdk/getting-started) walkthrough uses **Base Sepolia**.
Fund the account with test ETH on that network before sending a transfer.

## Arc amounts

Arc uses USDC for native value transfers and gas. Native amounts have 18 decimals:
`parseEther("1")` represents 1 native USDC on Arc. Its ERC-20 USDC interface uses
6 decimals: `parseUnits("1", 6)` represents 1 USDC in a token transfer. Both
interfaces share one balance. Use the units expected by the selected operation.

Install the session key on the selected Arc network before using it. Existing
permissions and chain allowlists do not automatically include a newly supported
network. The USDC Spend Template grants an ERC-20 lifetime allowance per network;
it does not grant a native-value allowance or sponsorship.

## Select a Network

Import `SupportedEvmChainId` from the SDK to type a network in your configuration:

```ts title="index.ts"
import { NameraClient, type SupportedEvmChainId } from "@namera-ai/sdk";

const namera = new NameraClient({
  apiKey: process.env.NAMERA_API_KEY!,
});

const chainId: SupportedEvmChainId = "eip155:84532";
const result = await namera.sessionKeys.get("0199dfe1-0000-7000-8000-000000000002");

if (!result.success) throw new Error(result.error.message);

const installation = result.data.installations.find(
  (entry) => entry.chainId === chainId && entry.status === "installed",
);

if (!installation) throw new Error("Install this session key on Base Sepolia first.");
```

Replace the example session-key ID with your own. An installation on one network
does not authorize another. Its validity period and permissions must also allow
your operation.

Changing `chainId` selects a network; it does not move funds between networks.
Use the recipient or contract address for the network you selected.

If a request returns `NETWORK_PAUSED`, wait for that network to be re-enabled
before submitting a new operation. You can still check existing submissions.
