`namera.wallets.get(walletId)` returns an account available to your credential.

## Usage

Install `@namera-ai/sdk` and set `NAMERA_API_KEY`. Replace example IDs with resources available to your credential.

<Tabs items={["index.ts", "client.ts"]}>
<Tab value="index.ts">

```ts title="index.ts"
import { namera } from "./client";
const result = await namera.wallets.get("0199dfe1-0000-7000-8000-000000000001");
if (!result.success) throw new Error(result.error.message);

console.log(result.data);
```

## Returns

<include>../../../../snippets/sdk/result.md</include>

- **`id`** (`string`): Account ID.
- **`organizationId`** (`string`): Owning organization ID.
- **`metadata`** (`object`): version and name, with optional logo and description.
- **`status`** (`"active" | "frozen" | "archived"`): Account lifecycle status.
- **`namespace`** (`"eip155"`): Chain namespace.
- **`address`** (`` `0x${string}` ``): Smart-account address.
- **`owner`** (`object`): Public signing-key identity, custody, algorithm, and provider-specific protection details.
- **`implementation`** (`"alchemy-modular-v2"`): Smart-account implementation.
- **`data`** (`object`): Account configuration, discriminated by validatorType and accountMode. Includes deployment and version fields.
- **`createdAt`** (`DateTime.Utc`): Creation time.
- **`updatedAt`** (`DateTime.Utc`): Last update time.

## Errors

`WALLET_NOT_FOUND` means the account does not exist or is not available to your credential. See [Handling Results and Errors](/docs/sdk/handling-results-and-errors)
for authentication, transport, and contract errors.
