`new NameraClient(config)` creates a client. Construction does not authenticate or send an API request.

## Usage

```sh
npm install @namera-ai/sdk
```

```ts title="index.ts"
import { NameraClient } from "@namera-ai/sdk";

const namera = new NameraClient({ apiKey: process.env.NAMERA_API_KEY! });
```

## Advanced Signing

Node.js resolves locally imported session keys automatically. A custom resolver takes precedence and must return an independently trusted installation binding. Browser clients do not include native key storage.

Low-level prepare and complete methods do not perform the high-level signing validation for you. Prefer `execute()` and `sign()` for normal integrations.
