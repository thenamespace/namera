`namera.executions.simulate(request)` does not sign, submit, or sponsor an operation.

## Usage

Install `@namera-ai/sdk` and `viem`. Replace the example IDs and recipient with your own. The selected session must permit these calls on Base Sepolia.

<Tabs items={["index.ts", "client.ts"]}>
<Tab value="index.ts">

```ts title="index.ts"
import { namera } from "./client";
import type { SimulateExecutionRequest } from "@namera-ai/sdk";
import { parseEther } from "viem";

const request = {
  namespace: "eip155",
  walletId: "0199dfe1-0000-7000-8000-000000000001",
  sessionKeyId: "0199dfe1-0000-7000-8000-000000000002",
  chainId: "eip155:84532",
  calls: [
    {
      to: "0x2222222222222222222222222222222222222222",
      value: parseEther("0.001"),
      data: "0x",
    },
  ],
} satisfies SimulateExecutionRequest;

const simulation = await namera.executions.simulate(request);
if (!simulation.success) throw new Error(simulation.error.message);

console.log(simulation.data);
```

## Returns

<include>../../../../snippets/sdk/result.md</include>

- **`namespace`** (`"eip155"`): Chain namespace.
- **`walletId`** (`string`): Account UUID.
- **`chainId`** (`SupportedEvmChainId`): Simulation network.
- **`account`** (`` `0x${string}` ``): Smart-account address.
- **`callsSucceeded`** (`boolean`): Whether the simulated calls succeeded.
- **`simulation`** (`EvmIntentSimulation`): userOperation gas estimates and calls results, assetChanges, and transfers.
- **`allowed`** (`boolean`): Point-in-time policy decision; not a guarantee of later execution.
- **`sessionKeyId`** (`string`): Present when allowed is true.
- **`denials`** (`readonly { sessionKeyId: string; policyId: string; code: EvmPolicyDenialCode }[]`): Nonempty when allowed is false; absent when allowed is true.

## Parameters

Pass a `SimulateExecutionRequest` object. Simulation does not accept a `sponsor` field.

for authentication, transport, and contract errors.
