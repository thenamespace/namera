`namera.executions.getStatus(submissionId)` tracks a submission before and after confirmation.

## Usage

```ts title="index.ts"
import { NameraClient } from "@namera-ai/sdk";

const namera = new NameraClient({ apiKey: process.env.NAMERA_API_KEY! });

const result = await namera.executions.getStatus("0199dfe1-0000-7000-8000-000000000003");
if (!result.success) throw new Error(result.error.message);

console.log(result.data);
```

Returns a promise containing a [NameraResult](/docs/sdk/handling-results-and-errors).
These fields describe successful `data`. JSON values are illustrative; date-time
values use ISO strings and bigint values use decimal strings in JSON.

## States

- `reserved`: awaiting authorization.
- `prepared`: signed and queued for broadcast.
- `submitted`: observed by the bundler.
- `confirmed`: includes the successful execution record.
- `failed`: terminal failure; no execution or hash field.

Poll the same ID while pending; stop on confirmed or failed. This method does not poll automatically.

## Errors

`EXECUTION_SUBMISSION_NOT_FOUND` means the submission is missing or unavailable to your credential. See [Handling Results and Errors](/docs/sdk/handling-results-and-errors) for shared authentication, transport, and contract errors.
