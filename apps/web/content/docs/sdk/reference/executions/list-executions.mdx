import { TypeTable } from "fumadocs-ui/components/type-table";

`namera.executions.list(options?)` returns confirmed history. Pending submissions are not included.

## Usage

```ts title="index.ts"
import { NameraClient } from "@namera-ai/sdk";

const namera = new NameraClient({ apiKey: process.env.NAMERA_API_KEY! });

const result = await namera.executions.list({
  walletId: "0199dfe1-0000-7000-8000-000000000001",
});
if (!result.success) throw new Error(result.error.message);

console.log(result.data);
```

There is no page-size parameter. Keep the same filters when requesting the next cursor.

## Returns

Returns a promise containing a [NameraResult](/docs/sdk/handling-results-and-errors).
These fields describe successful `data`. JSON values are illustrative; date-time
values use ISO strings and bigint values use decimal strings in JSON.

## Errors

Invalid filter IDs return a contract error. API failures return `success: false`. See [Handling Results and Errors](/docs/sdk/handling-results-and-errors) for shared authentication, transport, and contract errors.
