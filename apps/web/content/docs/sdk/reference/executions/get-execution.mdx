`namera.executions.get(executionId)` returns the full confirmed record.

## Usage

```ts title="index.ts"
import { NameraClient } from "@namera-ai/sdk";

const namera = new NameraClient({ apiKey: process.env.NAMERA_API_KEY! });

const result = await namera.executions.get("0199dfe1-0000-7000-8000-000000000012");
if (!result.success) throw new Error(result.error.message);

console.log(result.data);
```

## Parameters

<TypeTable
  type={{
    executionId: {
      type: "string",
      description: "Confirmed execution UUID from list or getStatus(). Not a submission ID.",
      required: true,
    },
  }}
/>

## Returns

Returns a promise containing a [NameraResult](/docs/sdk/handling-results-and-errors).
These fields describe successful `data`. JSON values are illustrative; date-time
values use ISO strings and bigint values use decimal strings in JSON.

## Errors

`EXECUTION_NOT_FOUND` means the confirmed record is missing or unavailable to your credential. See [Handling Results and Errors](/docs/sdk/handling-results-and-errors) for shared authentication, transport, and contract errors.
