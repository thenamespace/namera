`namera.executions.get(executionId)` returns the full confirmed record.

## Usage

Install `@namera-ai/sdk` and set `NAMERA_API_KEY`. Replace example IDs with resources available to your credential.

<Tabs items={["index.ts", "client.ts"]}>
<Tab value="index.ts">

```ts title="index.ts"
import { namera } from "./client";
const result = await namera.executions.get("0199dfe1-0000-7000-8000-000000000012");
if (!result.success) throw new Error(result.error.message);

console.log(result.data);
```

## Returns

<include>../../../../snippets/sdk/result.md</include>

- **`execution`** (`ExecutionResponse`): id, executionSubmissionId, organizationId, sessionKeyGrantId, namespace, data, and createdAt.
- **`execution.data`** (`EvmExecutionData`): version, namespace, chainId, calls, userOperationHash, transactionHash, and receipt.
- **`execution.data.receipt`** (`SuccessfulEvmExecutionReceipt`): Successful user-operation receipt including block, gas, sender, and EntryPoint.
- **`wallet`** (`WalletResponse`): Complete account record.
- **`sessionKey`** (`SessionKeySummaryResponse`): Session identity, metadata, policies, lifecycle, and creation fields without expanded relations.
- **`actor`** (`ExecutionActorDetailsResponse`): Discriminated by type. user has member; api-key has apiKey; cli and mcp have authorization. Includes id and public credential details, never raw secrets.

## Parameters

### executionId

- **Type:** `string`
- **Required**

The confirmed execution’s `id`, returned by `executions.list()` or inside the confirmed `getStatus()` execution record. Submission IDs and transaction hashes are different identifiers and cannot be used here.

```ts title="index.ts"
import { namera } from "./client";
const result = await namera.executions.get("0199dfe1-0000-7000-8000-000000000012"); // [!code focus]
if (!result.success) throw new Error(result.error.message);

console.log(result.data);
```

## Errors

`EXECUTION_NOT_FOUND` means the confirmed record is missing or unavailable to your credential. See [Handling Results and Errors](/docs/sdk/handling-results-and-errors) for shared authentication, transport, and contract errors.
