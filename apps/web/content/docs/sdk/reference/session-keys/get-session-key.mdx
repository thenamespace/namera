import { Tab, Tabs } from "fumadocs-ui/components/tabs";

`namera.sessionKeys.get(sessionKeyId)` returns the key, its account, creator, and installations.

## Usage

Install `@namera-ai/sdk` and set `NAMERA_API_KEY`. Replace example IDs with resources available to your credential.

<Tabs items={["index.ts", "client.ts"]}>
<Tab value="index.ts">

```ts title="index.ts"
import { namera } from "./client";
const result = await namera.sessionKeys.get("0199dfe1-0000-7000-8000-000000000002");
if (!result.success) throw new Error(result.error.message);

console.log(result.data);
```

## Returns

<include>../../../../snippets/sdk/result.md</include>

- **`id`** (`string`): Session-key ID.
- **`organizationId`** (`string`): Owning organization.
- **`walletId`** (`string`): Account ID.
- **`signingKeyId`** (`string`): Signing-key identity.
- **`namespace`** (`"eip155"`): Chain namespace.
- **`metadata`** (`object`): version and name, with optional logo and description.
- **`policies`** (`readonly Policy[]`): Additional API policies.
- **`policyHash`** (`string`): Stored policy hash.
- **`status`** (`"pending" | "active" | "revoking" | "revoked"`): Session lifecycle status.
- **`revokedAt`** (`DateTime.Utc | null`): Revocation time, if revoked.
- **`createdAt`** (`DateTime.Utc`): Creation time.
- **`signer`** (`object`): Public signer identity and custody. No private key.
- **`wallet`** (`WalletResponse`): Complete account record.
- **`creator`** (`object`): Human member/user/role details, or an API-key descriptor with `type`, `actorId`, `id`, and `metadata`.
- **`installations`** (`readonly Installation[]`): Each has id, chainId, status, authorization, installTransactionHash, and uninstallTransactionHash. Authorization includes permissions, signature authority, and validity timestamps.

## Errors

`SESSION_KEY_NOT_FOUND` means the key does not exist or is not available to your credential. See [Handling Results and Errors](/docs/sdk/handling-results-and-errors)
for authentication, transport, and contract errors.
