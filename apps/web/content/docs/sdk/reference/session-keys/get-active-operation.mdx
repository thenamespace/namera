`namera.sessionKeys.getActiveOperation()` recover an active installation or removal operation.

import { Tab, Tabs } from "fumadocs-ui/components/tabs";

## Usage

Install `@namera-ai/sdk` and set `NAMERA_API_KEY` on your backend. IDs and responses below are illustrative fixtures; replace IDs with your own resources.

<Tabs items={["index.ts", "client.ts"]}>
<Tab value="index.ts">

```ts title="index.ts"
import { namera } from "./client";
const result = await namera.sessionKeys.getActiveOperation({
  sessionKeyId: "0199dfe1-0000-7000-8000-000000000003",
  chainId: "eip155:11155111",
  kind: "install",
});
if (!result.success) throw new Error(result.error.message);

console.log(result.data);
```

## Returns

<include>../../../../snippets/sdk/result.md</include>

Returns `operation: null` when there is no active operation for this actor and target. Otherwise the operation contains `operationId`, `status`, and `preparation`. An unexpired unsigned operation returns a fresh preparation using its original internal idempotency key; signed/submitted operations have `preparation: null`. The SDK never exposes the stored retry key.

## Parameters

### sessionKeyId

Type: `string`. Required. Session UUID. Requires session read access to resolve the installation.

```ts title="index.ts"
import { namera } from "./client";
const result = await namera.sessionKeys.getActiveOperation({
  sessionKeyId: "0199dfe1-0000-7000-8000-000000000003", // [!code focus]
  chainId: "eip155:11155111",
  kind: "install",
});
if (!result.success) throw new Error(result.error.message);

console.log(result.data);
```

### chainId

Type: `SupportedEvmChainId`. Required. Configured CAIP-2 network ID.

```ts title="index.ts"
import { namera } from "./client";
const result = await namera.sessionKeys.getActiveOperation({
  sessionKeyId: "0199dfe1-0000-7000-8000-000000000003",
  chainId: "eip155:11155111", // [!code focus]
  kind: "install",
});
if (!result.success) throw new Error(result.error.message);

console.log(result.data);
```

### kind

Type: `"install" | "uninstall"`. Required. The operation type you want to recover.

```ts title="index.ts"
import { namera } from "./client";
const result = await namera.sessionKeys.getActiveOperation({
  sessionKeyId: "0199dfe1-0000-7000-8000-000000000003",
  chainId: "eip155:11155111",
  kind: "install", // [!code focus]
});
if (!result.success) throw new Error(result.error.message);

console.log(result.data);
```

## Behavior and errors

Requires `session-key:read`; recovering an unsigned preparation also requires its install/uninstall permission. API keys recover only their own operations. If `preparation` is present, review it and explicitly approve. If the operation is signed or submitted, poll it. Cancel an unsigned operation before deliberately preparing a replacement. Recovery does not create or install a new session.
