`namera.sessionKeys.getOperation()` read the status of an installation or removal operation.

import { Tab, Tabs } from "fumadocs-ui/components/tabs";

## Usage

Install `@namera-ai/sdk` and set `NAMERA_API_KEY` on your backend. IDs and responses below are illustrative fixtures; replace IDs with your own resources.

<Tabs items={["index.ts", "client.ts"]}>
<Tab value="index.ts">

```ts title="index.ts"
import { namera } from "./client";
const result = await namera.sessionKeys.getOperation("0199dfe1-0000-7000-8000-000000000014");
if (!result.success) throw new Error(result.error.message);

console.log(result.data);
```

## Returns

<include>../../../../snippets/sdk/result.md</include>

Returns `operationId` and `status`: `awaiting-signature`, `signed`, `submitted`, `confirmed`, `failed`, `expired`, or `cancelled`. Only `confirmed` establishes successful receipt confirmation.

<div className="docs-response">

```json
{
  "operationId": "0199dfe1-0000-7000-8000-000000000014",
  "status": "confirmed"
}
```

</div>

## Parameters

### operationId

Type: `string`. Required. Resource UUID returned by creation, preparation, or recovery; not an address or transaction hash.

```ts title="index.ts"
import { namera } from "./client";
const result = await namera.sessionKeys.getOperation("0199dfe1-0000-7000-8000-000000000014"); // [!code focus]
if (!result.success) throw new Error(result.error.message);

console.log(result.data);
```

## Behavior and errors

Requires `session-key:read`. API keys can poll only operations initiated by that same actor. `OPERATION_UNAVAILABLE` covers missing, foreign-workspace, and other-actor operations. A missing receipt leaves an operation pending; do not start another installation simply because polling is slow.
