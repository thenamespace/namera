This is separate from `namera login`. Approve only the session keys and MCP
permissions the agent needs. Credentials persist in the OS keyring. If the
browser cannot open, follow the printed URL. Imported signing keys must be
available to the OS user running the MCP process.

## Errors

Failures exit nonzero and are written to stderr. With `--output json`, inspect
`error.code` and `error.nextStep`. See [Output and Errors](/docs/cli/output-and-errors).
