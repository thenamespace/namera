Revoke and disconnect an MCP connection.

## Usage

```sh
namera mcp logout --profile default
```

Logout attempts server-side revocation and clears local authority. If revocation
fails, the command reports an error; revoke the connection in the dashboard.
Accounts and imported signing keys are not removed. Use ordinary `namera logout`
to remove an ordinary CLI connection.

## Errors

Failures exit nonzero and are written to stderr. With `--output json`, inspect
`error.code` and `error.nextStep`. See [Output and Errors](/docs/cli/output-and-errors).
