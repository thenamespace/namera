Read one account by ID or choose it interactively.

## Usage

```sh
namera wallet get 0199dfe1-0000-7000-8000-000000000001
```

## Arguments

### wallet-id

- **Type:** `string` (UUID)
- **Required:** outside an interactive terminal

Use an ID returned by `wallet list --output json`, not an address. Omit it in an
interactive terminal to open a picker. The picker is unavailable with JSON output,
quiet mode, or redirected streams.
