Preview calls and check installed permissions without submitting a transaction.

## Usage

```sh
namera execution simulate \
  --namespace evm \
  --wallet 0199dfe1-0000-7000-8000-000000000001 \
  --session-key 0199dfe1-0000-7000-8000-000000000002 \
  --network 'Base Sepolia' \
  --to 0x2222222222222222222222222222222222222222 \
  --value 1000000000000000 \
  --data 0x
```

## Interpreting the Preview

Review the simulated call results. Authorization and simulation failures return
errors. Successful previews do not reserve billing allowance or guarantee later execution.

This command has no `--sponsor` or `--max-gas-cost-wei` flag.

## Errors

Failures exit nonzero and are written to stderr. With `--output json`, inspect
`error.code` and `error.nextStep`. See [Output and Errors](/docs/cli/output-and-errors).
