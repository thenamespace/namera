Inspect the credential and permissions used by ordinary CLI commands.

## Usage

```sh
namera auth status
```

Human output may also read accounts and session keys to show their names and
installation expiry when your scopes permit those reads. JSON returns `profile`
and the full `actor` without those additional requests. This is an authenticated
API check, not just a check for a saved token.

## Errors

Failures exit nonzero and are written to stderr. With `--output json`, inspect
`error.code` and `error.nextStep`. See [Output and Errors](/docs/cli/output-and-errors).
