Read a session key's installed permissions and API policies.

## Usage

```sh
namera session-key get 0199dfe1-0000-7000-8000-000000000002
```

## Arguments

### session-key-id

- **Type:** `string` (UUID)
- **Required:** outside an interactive terminal

Use an ID from `session-key list --output json`. Omit it in a terminal to pick a
key by its name and account. Scripts, JSON output, and quiet mode require the ID.
