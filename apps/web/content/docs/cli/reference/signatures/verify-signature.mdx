Check an account signature against its original payload.

## Usage

```sh
namera verify-signature \
  --namespace evm \
  --wallet 0199dfe1-0000-7000-8000-000000000001 \
  --network 'Base Sepolia' \
  --type message \
  --message 'Hello from Namera' \
  --signature <hex-signature>
```

### --signature

- **Type:** even-length `0x`-prefixed hex
- **Required:** for non-interactive input flags

Pass the complete signature returned by `namera sign`, with the same account,
network, and original message or typed data. Do not strip its smart-account prefix.

There is no `--session-key` option. Verification establishes whether the account
accepts the signature; it does not identify which session key signed.

A successful command may return `valid: false`. Scripts must inspect this
field rather than treating exit code zero as proof of validity.

## Errors

Failures exit nonzero and are written to stderr. With `--output json`, inspect
`error.code` and `error.nextStep`. See [Output and Errors](/docs/cli/output-and-errors).
