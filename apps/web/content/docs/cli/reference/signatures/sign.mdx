Sign a UTF-8 message or EIP-712 typed data with an account.

## Usage

```sh
namera sign \
  --namespace evm \
  --wallet 0199dfe1-0000-7000-8000-000000000001 \
  --session-key 0199dfe1-0000-7000-8000-000000000002 \
  --network 'Base Sepolia' \
  --type message \
  --message 'Hello from Namera'
```

The session's installed authority must allow signatures and any applicable API
policies must allow the payload. Signing does not broadcast a transaction.
Do not blindly repeat a signing command after losing its response; another
attempt can consume another signature allowance.

## Errors

Failures exit nonzero and are written to stderr. With `--output json`, inspect
`error.code` and `error.nextStep`. See [Output and Errors](/docs/cli/output-and-errors).
