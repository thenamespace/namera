The Namera CLI connects your terminal and AI agents to accounts through
authorized session keys. Use prompts to explore, explicit flags for scripts,
or the built-in MCP server to connect an agent.

## Quick Examples

Install the [CLI](/docs/cli/installation), complete
[account setup](/docs/cli/getting-started), and sign in with `namera login`.

### List Accounts

```sh
namera wallet list
```

<include>../../snippets/cli/output/wallet-list.md</include>

### Sign a Message

```sh
namera sign --type message --message 'Hello from Namera'
```

In a terminal, choose the account, session key, and network when prompted.
The key must allow signatures on that network.

<include>../../snippets/cli/output/sign.md</include>

### Execute a Transaction

```sh
namera execution execute
```

Choose an account and key, then supply the network, recipient, value in wei,
calldata, and gas sponsorship choice. The command submits the transaction.
Use `namera execution simulate` for a preview instead.

<include>../../snippets/cli/output/execute.md</include>

Save the submission ID and check it with `namera execution status`. Submission
is not confirmation.

<include>../../snippets/cli/output-note.md</include>
