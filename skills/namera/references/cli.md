# CLI

Follow [Getting Started](https://namera.ai/docs/cli/getting-started.md) for setup
and account reads. [Authentication](https://namera.ai/docs/cli/authentication.md)
covers browser login and API keys; [Profiles and Configuration](https://namera.ai/docs/cli/profiles-and-configuration.md)
covers profile and host selection.

- Inspect or import a key: [Accounts and Session Keys](https://namera.ai/docs/cli/accounts-and-session-keys.md).
  Importing a key does not install its onchain permissions.
- Write a script: [Scripts and CI](https://namera.ai/docs/cli/guides/automation/run-in-scripts-and-ci.md).
  Supply required inputs explicitly and use JSON output.
- Handle a command failure: [Output and Errors](https://namera.ai/docs/cli/output-and-errors.md).
- Sign: [Messages](https://namera.ai/docs/cli/guides/signing/sign-messages.md) or
  [Typed Data](https://namera.ai/docs/cli/guides/signing/sign-typed-data.md).
- Verify: [Verify Signatures](https://namera.ai/docs/cli/guides/signing/verify-signatures.md).

Use the installed command's help for supported flags. SDK options are not CLI flags.
For transaction examples, read [Transactions](transactions.md).
