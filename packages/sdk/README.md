# @namera-ai/sdk

Scoped, revocable permissions for agent wallets on ERC-7579 smart accounts (Kernel, Nexus, Safe7579),
built on Namera's Smart Sessions. Work in progress.

## Development

| Command          | What it does                 |
| ---------------- | ---------------------------- |
| `pnpm build`     | Build `dist/` with tsdown    |
| `pnpm test`      | Run the tests (Vitest)       |
| `pnpm coverage`  | Tests with V8 coverage       |
| `pnpm typecheck` | Type-check sources and tests |
