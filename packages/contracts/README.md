# @namera-ai/contracts

ABIs, CREATE2 addresses and deployment provenance of Namera's Smart Sessions contracts. No runtime
dependencies: every export is generated data.

## Install

```sh
pnpm add @namera-ai/contracts
```

## Usage

Each contract is a namespace with one export per version. A version has the same address on every
chain; `deployments` holds its provenance per chain id.

```ts
import { SmartSession } from "@namera-ai/contracts"
import { encodeFunctionData, pad } from "viem"

const removeSessionCall = encodeFunctionData({
  abi: SmartSession.v1.abi,
  functionName: "removeSession",
  args: [pad("0x01", { size: 32 })]
})

SmartSession.v1.address // "0xe98939a39E5faA47861D9Af4f10689c90239d3D0"
SmartSession.v1.deployments[8453]?.blockNumber // creation block on Base, once deployed there
```

`Contract.Version`, `Contract.Deployment` and `Contract.Compiler` type the generated values.

## How it is generated

`src/` is generated by `pnpm contracts:generate` (`namera-dev contracts generate`) from the Foundry
build and the deployment records in [`contracts/deployments/`](../../contracts/deployments); never
edit it by hand. `pnpm check` runs `namera-dev contracts generate --check`, which fails when the
committed sources are stale or a record sits at another address than the current build deploys to.
